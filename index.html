01 / THE IDEA

The repository is the interface.

Hardware deserves the same composable, inspectable workflow as software.

PCBoo is not another visual editor and not another agent runtime. It gives coding agents a precise filesystem contract, deterministic commands, and compact results they can reason about.

Humans stay in the loop through a local inspection server—and can hand off to KiCad when fine manual adjustment is the right tool.

COMPOSE

Circuits are normal TypeScript.

Split the board into small, named components. Import and combine them just like application code.

02
import { Board, Circuit } from "pcboo";
import { addPower } from "./power";

export default function createCircuit() {
  const circuit = new Circuit();
  const board = new Board({
    width: "30mm", height: "20mm",
    layers: 4
  });
  addPower(board);
  circuit.add(board);
  return circuit;
}

03 / AGENT SKILLS

Skills that teach
the procedure.

Generated projects ship a versioned catalog of Agent Skills for Codex, Claude Code, Cursor, and compatible agents. Your agent learns the correct PCBoo procedure for each task — no guessing, no skipped gates.

ROUTER

pcboo-best-practices

Orient in a project and route work to the right procedure without weakening evidence or human gates.

DESIGN

pcboo-design

Create complete circuits as composable TypeScript — architecture, footprints, stack-up, placement, routing.

LAYOUT

pcboo-schematic-layout

Make schematics readable with authored logical coordinates and machine-checkable collision gates.

MODELS

pcboo-resolve-models

Resolve, vendor, license-check, and bind realistic component 3D models before the assembled preview.

DIAGNOSE

pcboo-diagnose

Repair one build, electrical, fabrication, test, simulation, KiCad, or manufacturing finding at a time.

VERIFY

pcboo-verify

Prove requirements with tests, Circuit JSON checks, qualified simulations, and independent evidence review.

MANUFACTURE

pcboo-manufacturing

Generate and independently verify Gerber, drill, BOM, and placement artifacts and KiCad handoffs.

ADD TO ANY PROJECT

skills add pcboo

Install the public catalog into an existing project. Copy mode keeps PCBoo's no-symlink boundary intact.

bunx --bun skills@latest add pcboo-dev/pcboo --copy
04 / EVIDENCE, NOT PROMISES
